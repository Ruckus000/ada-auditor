# Stage 1 Round 10 Implementation Plan — confidence scores and the regular-weight gap

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Measure whether adapter-r9's decisions carry a usable confidence signal (so the product can route uncertain cards to the reviewer and hold the confident subset to the Stage 1 bar), and close the one data gap round 9's error analysis exposed: regular-weight headings are 17 % of training headings but 34 % of validation headings, and r9 recalls them at 0.82 against 0.95 for bold.

**Architecture:** Task 1 is measurement only: re-run r9 on the fixed validation population with the log-probability of the type token captured, then report accuracy / FP / FN as a function of coverage when the least-confident cards abstain. Task 2 is one retrain with a registered oversampling of regular-weight heading rows in the existing labels (no new labels, no new code paths beyond an emit flag), measured with the round-9 method. Task 2 runs only if Task 1 does not already show the confident subset at the bar, or if Task 1 shows the confident subset is too small to be useful (< 50 % coverage).

**Tech Stack:** as round 9 (`labels/*.py`, MLX venv `~/.venvs/qwen-role-decisions`, `mlx-community/Qwen3.5-4B-MLX-4bit`, marked-408 images).

**Spec:** `docs/superpowers/plans/2026-09-13-staged-autonomy-roadmap.md` (abstention channel; Stage 1 bar), `docs/research/document-remediation/heading-stage1-r9-2026-09-16-results.md` (stop decision: measure before training again), `2026-09-16-stage1-round9.md` (Global Constraints carry over unchanged).

## Global Constraints

- All of round 9's Global Constraints apply verbatim: working directory, split, no test evaluation, label sources, level policy, c5 excluded, commit discipline, 15 h gate for any training run.
- **Registered before Task 1 runs:**
  - Population: the 1,525 validation rows; predictions are adapter-r9's, graded against `labels-audited-r9.jsonl`; rule-decided rows count as confidence 1.0 (they are deterministic).
  - Confidence: for model-decided rows, `p_H` = the model's probability mass on the token(s) that begin `"type":"H"` at the type position, normalised over the vocabulary's alternatives that begin a valid type (`H`, `P`, `Artifact`, `Caption`, `TH`, `TOCI`, `Lbl`, `BlockQuote`). Score = `max(p_H, 1 − p_H)`. If the runtime cannot expose per-token log-probabilities, fall back to sampling the same prompt 5 times at temperature 0.7 and using the vote share; record which was used.
  - Prediction: at the coverage where score ≥ 0.9, direct accuracy on the covered rows is ≥ 0.98 and coverage is ≥ 60 %. The Stage 1 bar (≥ 0.99 with lower bound, FP ≤ 0.01 with upper bound) on the covered subset is **hoped for, not expected**; the deliverable is the curve.
- **Registered before Task 2 runs:**
  - Data: `sft-r10` = `sft-r9` with every emitted H row whose card `weight` is `regular` duplicated once (oversample ×2). No other change. Expected size ≈ 4,475 + ~430.
  - Config: identical to r9 (`--iters` = 2 × row count, rank 8, same flags).
  - Prediction: r9 → r10, same labels and r9v rates: regular-weight recall rises from 0.82 to ≥ 0.88 with bold recall not falling below 0.94; estimated FN falls from 0.174 to ≤ 0.16; FP stays ≤ 0.05.
  - Kill: Task 2 does not run if Task 1's covered subset (score ≥ 0.9) already meets accuracy ≥ 0.99 and FP ≤ 0.01 at ≥ 50 % coverage — the product path is then abstention, and the next plan is the product's, not this loop's.
