# Stage 1 Round 9 Implementation Plan — audit-corrected training labels, retrain, and a symmetric measurement

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Turn the 804 training rows where the model and the key already disagree into audited labels, retrain once, and measure the new adapter the same way round 7 was measured so the two numbers are comparable.

**Architecture:** No new code paths. The round reuses the round-7 pipeline exactly (`keys-all-N` overlay → `emit_sft` → upstream `mlx_vlm.lora` → `predict` → `eligibility_eval evaluate`) with one input change: the two disagreement pools that round 7 left un-audited (266 flagged key-H rows and the 538 excluded proxy rows) are judged blind by the coordinator chat from marked page images, the same way `audit-r7AB` and `audit-r8` were, and take their audited labels in training. Measurement repeats the round-8 method on the new adapter's own error rows, so round 7 and round 9 are both graded on exhaustively audited errors.

**Tech Stack:** Python 3.14 stdlib modules under `experiments/qwen-role-decisions/labels/`; MLX venv `~/.venvs/qwen-role-decisions` (`mlx-vlm 0.7.0`, `mlx 0.32.2`); `mlx-community/Qwen3.5-4B-MLX-4bit` in the HF cache; JDK 17 + PDFBox for images (already rendered under `out/keys-all-{3,4}/pages/marked-408/`).

**Spec:** `docs/superpowers/plans/2026-09-13-staged-autonomy-roadmap.md` (Stage 1), `docs/research/document-remediation/heading-definition-2026-09-13.md` (§4 rules, §7 order), and the round records `heading-stage1-r7-2026-09-15-results.md` and `heading-stage1-r8-2026-09-15-results.md` (rulings 1–4, the audit method, the one-sided-comparison warning).

  - Population: the sft-r7 population (3,993 rows) plus every row of the 804-row audit pool that emit accepts under its audited type, minus rows the rules decide. Expected 4,400–4,800 rows.

The Stage 1 bar (accuracy ≥ 0.99 with lower bound, FP ≤ 0.01 with upper bound) is **expected to fail** again; the deliverable is a comparable pair of numbers and the errors-by-type table.
  - Kill (Task 1): if fewer than 55 % of the audited pool rows change label (audit agrees with the key more often than round 7's A and B did), the audit is not buying labels and Task 2 onward does not run; report and stop.

- [ ] **Step 1: Build the card set (implementing chat)**

```bash
cd experiments/qwen-role-decisions && python3 -B - <<'EOF'
import json, random
L="out/labels/"
g=json.load(open(L+"audit-r7AB-groups.json")); proxy=json.load(open(L+"audit-r7-proxy-ids.json"))["proxy"]
aud=set()
for f in ["audit-r6-claude.jsonl","audit-r7-claude.jsonl","audit-r7AB-claude.jsonl","audit-r8-claude.jsonl"]:
    for l in open(L+f): aud.add(json.loads(l)["id"])
A=[i for i in g["A_pool"] if i not in aud]; B=[i for i in proxy if i not in aud]
assert len(A)==266 and len(B)==538, (len(A),len(B))
split=json.load(open("out/keys-all-4/split/split.json"))["ids"]   # id -> "train" | "validation" | "test"
assert all(split.get(i)=="train" for i in A+B), "pool must be train-only"
ids=A+B; random.Random(20260916).shuffle(ids)
with open(L+"audit-r9-cards.jsonl","w") as f:
    for i in ids: f.write(json.dumps({"id":i})+"\n")
json.dump({"seed":20260916,"A_pool_remainder":A,"proxy_remainder":B,"note":"train ids only; no prediction in either file"}, open(L+"audit-r9-groups.json","w"), indent=1)
print("cards",len(ids),"docs",len({i.split(':')[0] for i in ids}))
EOF
```
Expected: `cards 804`.

- [ ] **Step 2: Hand over** — message the coordinator chat with the two paths and the count. The coordinator judges every card from `out/keys-all-{3,4}/pages/marked-408/<doc>_<n>.png` (path from `out/keys-all-4/cards-r5.jsonl` field `image`) with the card's `text`, `prev`, `next`, `font_pt`, `weight`, `repeats_on_pages`, `in_table_box`, and no prediction, and writes `audit-r9-claude.jsonl`. Budget: about 200 cards per hour of coordinator reading, so about 4 h.

- [ ] **Step 3: Score the audit (implementing chat)** — recompute, do not take the coordinator's figures on trust:

```bash
cd experiments/qwen-role-decisions && python3 -B - <<'EOF'
import json, collections
L="out/labels/"; g=json.load(open(L+"audit-r9-groups.json"))
labels={json.loads(l)["id"]:json.loads(l) for l in open("out/keys-all-4/labels.jsonl") if l.strip()}
aud={json.loads(l)["id"]:json.loads(l) for l in open(L+"audit-r9-claude.jsonl")}
for name in ("A_pool_remainder","proxy_remainder"):
    ids=[i for i in g[name] if i in aud and not aud[i]["unsure"]]
    changed=sum(labels[i]["label"]["heading"]!=aud[i]["label"]["heading"] for i in ids)
    print(name, "scored",len(ids),"H",sum(aud[i]["label"]["heading"] for i in ids),"label changes",changed, round(changed/len(ids),2))
    print("  types", dict(collections.Counter(aud[i]["type"] for i in ids)))
allids=[i for i in aud if not aud[i]["unsure"]]
chg=sum(labels[i]["label"]["heading"]!=aud[i]["label"]["heading"] for i in allids)
print("ALL scored",len(allids),"changes",chg, round(chg/len(allids),2), "unsure", sum(a["unsure"] for a in aud.values()))
EOF
```
Expected from r7's A and B: proxy remainder about 0.74 H, A remainder about 0.15 non-H, overall label-change share about 0.55–0.65. **Kill check:** if the overall change share is below 0.55, stop here, write the record section "Round 9 stopped at the kill", and report.
