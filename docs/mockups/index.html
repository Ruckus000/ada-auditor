Three directions for a friendlier audit console

These are static, self-contained HTML proposals using the same representative audit state. Each one changes the hierarchy, density, geometry, and interaction model—not just the color palette.

Audit Flow

Vercel/shadcn-inspired: dark, beginner-friendly setup flow that makes the safe path and evidence trade-offs explicit.

Confidence Workspace

Google Material-inspired: airy, guided, plain-language flow that makes evidence confidence visible.

Release Board

Atlassian-inspired: project shell, tabs, lozenges, issue triage, and traceability for team review.
