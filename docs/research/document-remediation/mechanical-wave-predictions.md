# The mechanical wave — headings, fonts, CIDToGIDMap — predictions

Registered before the blind run that tests them. The product code exists and is
unit-verified (negative controls run against the pre-change classes; every new
JVM test fails there and passes after); what has NOT run is the corpus, and
this is the record of what it must show. Counts, ids and clause identifiers
only.

## The three changes

1. **`--renumber-headings`** (conversion lane only): exporter-seated ladders
   re-ranked onto H1, rank-preserving, RoleMap-refused. Decided by the user as
   a standing policy over the recorded "a person decides".
2. **`--embed-fonts`** (repair lane only): metric-identical Liberation
   programs attached to non-embedded Windows-face TrueType fonts, widths
   proven per font within 0.5/1000 em, refusal-first on eight distinct guards.
3. **CIDToGIDMap rider** (both lanes, unconditional): an embedded
   CIDFontType2 lacking the entry gains `/Identity` — the ISO 32000 default
   every reader already applies, stated rather than implied.

## Watched risks, named before the run

- **n08 is the least-verified of the four font documents** — its widths passed
  the bulk comparison but it was not one of the three individually confirmed.
  If it refuses, the +5 is a +4 and the miss is recorded, not smoothed.
- **Contrast could wobble.** The contrast stage samples rendered pixels, and
  embedding changes which glyphs render on repaired documents. Real keys hold
  needs as must-include, so movement surfaces as probe notes, not fatals — but
  any 1.4.3 movement gets counted and explained, not waved off.
- **The stamp pass re-runs Finish with the same request.** A font embedded on
  the first pass is skipped as embedded on the second (the guard tests
  FontFile2 presence), so the stamped file must be content-identical — the
  fidelity gate at the swap will prove it on every stamped document.

If a document outside the five conforms, a planted row moves, or a clause
outside {7.4.2-1, 7.21.4.1-1, 7.21.3.2-1, 5-1} leaves any list, the wave did
something it was not supposed to do and stops for review.
