Quickstart

Create a bucket

Install the CLI, then create your first bucket in the region closest to you.

kestrel bucket create nightly-snapshots --region eu-west

Signed URLs

A signed URL expires after the number of seconds you pass to --ttl.

kestrel url sign nightly-snapshots/db.sql --ttl 900
